# esaKITs — Side-by-Side FlashCards

**A-2 Side-by-Side FlashCards v1.0**

Japanese flashcards for learning and teaching **hiragana, katakana, romaji, Japanese counters, time and calendar expressions**. 問題と答えを左右に配置して使える、日本語教育向けのブラウザ版フラッシュカードです。Teacher Mode と Learner Mode の両方に対応しています。

## 使う

GitHub Pages 公開版：

```text
https://esakits.github.io/japanese-flashcards-side-by-side/
```

ブラウザで開くだけで利用できます。インストールは不要です。

## 主な機能

- Teacher Mode / Learner Mode
- 左右型カード表示
- 問題／答えの入れ替え
- ひらがな・カタカナ・ローマ字
- カタカナの答えをローマ字／ひらがなから選択
- 行単位の出題範囲選択
- 拗音・特殊拍・カタカナ特殊音
- 順番／シャッフル
- 数え方（助数詞）
- 時・時間・分・日にち・月・歳
- 複数読みの表示
- 自作セットの読み込み
- CSV / TSV / TXT / JSON の読み込み・保存
- 問題側・答え側を別々に表示設定
- PC内フォントの読み込み
- UD Digi Kyokasho / UD Kyokasho 系フォントの優先表示
- 自動改行／任意改行／改行せず自動縮小
- 表示設定プレビュー
- 全画面表示
- スマホ縦持ち／横持ち対応

## 基本的な使い方

1. 教材を選びます。
2. 「問題」「答え」「表記」「出題順」を設定します。
3. 必要に応じて出題範囲や表示設定を調整します。
4. Teacher Modeでは［次へ］1回目で答えを表示し、2回目で次の問題へ進みます。
5. Learner Modeでは、学習者が入力して正誤判定できます。

## 自作セット

CSV / TSV / TXT では、2列以上の任意の列名を利用できます。

```text
ます形,て形,辞書形
かきます,かいて,かく
のみます,のんで,のむ
```

読み込み後に、どの列を「問題」「答え」として使うか選択できます。

## PC内フォントについて

「PCのフォントを読み込む」は、対応ブラウザの Local Font Access 機能を利用します。対応していない環境でも、基本的なフラッシュカード機能は利用できます。
